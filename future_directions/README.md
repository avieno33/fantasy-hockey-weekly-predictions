# Future Directions

This folder holds notes on extensions being considered but not yet
built, and on things that were tested and didn't hold up, with the
reasoning kept on record rather than just discarded. Each file
describes the idea, why it's not part of the current model, and what
would need to be true to revisit it.

Status of items in this folder will be updated as the base model
develops, some ideas here may already be resolved or superseded once
checked against the current notebook.
